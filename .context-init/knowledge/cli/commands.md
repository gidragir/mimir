# 🛠 Справочник команд: mimir (L2)

> Автоматически извлечено из конфигурации проекта (Kotlin (Gradle))

## Стандартные команды жизненного цикла

| Задача | Команда |
| :--- | :--- |
| **Сборка** | `rtk mise run build` |
| **Тестирование** | `rtk mise run test` |
| **Запуск** | `rtk mise run desktop` |
