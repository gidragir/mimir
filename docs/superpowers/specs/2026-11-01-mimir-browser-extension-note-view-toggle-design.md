# Mimir: Спецификация переключателя режима отображения заметки в расширении (`:browser-extension`)

**Дата:** 2026-11-01  
**Статус:** Proposal  
**Область:** `browser-extension`

---

## 1. Назначение и контекст (Intent & Why)

В ридере заметки браузерного расширения Mimir присутствовали кнопки копирования «📋 MD» и «📄 Текст», которые помещали сырой Markdown или очищенный текст в буфер обмена. Пользователю необходимо не копирование, а переключение между отрендеренным представлением (HTML / SafeMarkdownRenderer) и исходным текстом заметки (сырой Markdown) аналогично Obsidian (кнопка переключения режимов чтения и редактирования/исходника).

---

## 2. Цели, не-цели, анти-цели

### Цели
1. Заменить кнопки «📋 MD» и «📄 Текст» в тулбаре ридера заметки на одну кнопку-переключатель (toggle) в стиле Obsidian.
2. Поддерживать два режима отображения активной заметки:
   - `RENDERED` (по умолчанию): отрендеренный HTML через `SafeMarkdownRenderer`;
   - `SOURCE`: отображение исходного текста Markdown в моноширинном блоке `<pre class="raw-markdown-body"><code data-testid="raw-markdown-content">`.
3. Сохранять изоляцию режима: состояние режима просмотра локально для текущей открытой заметки, в постоянное хранилище не пишется, при открытии любой новой заметки всегда активируется режим `RENDERED`.

### Не-цели
- Редактирование Markdown в браузере (заметки остаются read-only).
- Сохранение выбранного режима между переключениями заметок или между перезапусками расширения.

### Анти-цели
- Мутация состояния без UDF (не делать DOM-хаков в обход `ExtensionUiState` / `ExtensionController`).
- Использование небезопасных методов вставки HTML для сырого Markdown.

---

## 3. Рассмотренные подходы (Approaches)

1. **Глобальный сессионный режим (в `ExtensionController` / `sessionStorage`):**
   - *Плюсы:* выбранный режим сохраняется при переходе от заметки к заметке.
   - *Минусы:* не соответствует требованию пользователя.
   - *Статус:* отклонён.

2. **Локальный режим для активной заметки без персистентности (Выбран):**
   - *Плюсы:* простота реализации, строгое соответствие запросу: при переключении заметки всегда открывается режим `RENDERED`.
   - *Реализация:* поле `viewMode: NoteViewMode = NoteViewMode.RENDERED` в `ActiveNoteState.Loaded` (или в `ExtensionUiState.VaultReady`). При вызове `controller.toggleNoteViewMode()` меняется флаг у текущей загруженной заметки. При вызове `controller.openNote(file)` создаётся новое состояние с дефолтным `NoteViewMode.RENDERED`.
   - *Статус:* выбран пользователем.

---

## 4. Инварианты Mimir

### 4.1 Платформы
- **Chromium MV3 (Side Panel, Popup, Reader Tab):** идентичное поведение во всех трех контекстах отображения.
- Другие платформы не затрагиваются.

### 4.2 Дизайн
- **UDF (Однонаправленный поток данных):** `PopupDomView` является чистой функцией состояния `ExtensionUiState`.
- `NoteViewMode` (`RENDERED`, `SOURCE`) объявляется в `ExtensionUiState.kt`.
- `ActiveNoteState.Loaded` дополняется свойством `val viewMode: NoteViewMode = NoteViewMode.RENDERED`.
- `ExtensionController` предоставляет метод `fun toggleNoteViewMode()`.

### 4.3 IO
- Изменение не производит сетевых вызовов и обращений к хранилищу.
- Переключение режима выполняется мгновенно в оперативной памяти (0 сетевых запросов, 0 обращений к Google Drive API).

### 4.4 UX
- Кнопка в тулбаре ридера:
  - В режиме `RENDERED`: иконка `📖` (или `👁`), подсказка `title="Режим чтения. Нажмите для показа Markdown"`, `data-testid="note-view-toggle-btn"`.
  - В режиме `SOURCE`: иконка `📝` (или `</>`), подсказка `title="Режим Markdown. Нажмите для показа разметки"`, `data-testid="note-view-toggle-btn"`.
- Контейнер заметки:
  - В режиме `RENDERED`: дерево элементов из `SafeMarkdownRenderer.render(...)`.
  - В режиме `SOURCE`: моноширинный элемент `<pre class="raw-markdown-body" data-testid="raw-markdown-view"><code data-testid="raw-markdown-content">` с переносом длинных строк (`white-space: pre-wrap; word-break: break-word`).

## 5. План тестирования и верификации
1. Unit-тесты в `CopyButtonsTest.kt` (переименовать/заменить на `NoteViewToggleTest.kt`):
   - Проверка, что кнопки «📋 MD» и «📄 Текст» отсутствуют.
   - Проверка наличия кнопки переключателя `note-view-toggle-btn`.
   - По умолчанию отображается отрендеренный Markdown (`.markdown-body`).
   - По клику на кнопку тело переключается на `<pre class="raw-markdown-body">` с сырым текстом заметки.
   - По повторному клику возвращается отрендеренный Markdown.
   - При переходе на другую заметку режим сбрасывается обратно в `RENDERED`.
2. Запуск тестов модуля через `mise run test` / `gradle :browser-extension:jsTest`.
